# Доплер эффект

Status: public alpha migration. The tool is preserved as a standalone static canvas/Web Audio folder.

Original source note: migrated from the local raw import archive into `tools/doppler/` (moved to `doppler/` on 2026-11-07). `_import/` remains local-only and ignored.

Language: Mongolian.

Known limitations:

- Browser audio policies may require a click or tap before sound can play.
- Audio quality and timing have not been subjectively revalidated.
- The animations use legacy global JavaScript state.
- `doppler.js` appears to be an unused duplicate or older sound script, but it has not been deleted.
